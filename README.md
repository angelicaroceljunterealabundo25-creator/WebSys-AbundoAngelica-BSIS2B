## Weekly Summary

### Week 1 - HTML Fundamentals
Created a basic webpage using HTML5 and practiced organizing content with headings, paragraphs, links, images, and other essential HTML elements. This activity helped me understand the structure of a webpage.

### Week 2 - Semantic & Multimedia
Applied semantic HTML elements to organize webpage content and practiced adding multimedia elements. This activity helped me understand how to make webpages more meaningful and engaging.

### Week 3 - CSS Basics
Used CSS to customize webpage appearance through colors, fonts, spacing, selectors, and layout properties. This activity helped me improve the visual presentation and readability of a webpage.

### Week 4 - JavaScript Basics and DOM Manipulation
Practiced JavaScript fundamentals and DOM manipulation to make webpage elements interactive. This activity helped me understand how JavaScript can respond to user actions and dynamically update webpage content.

### Week 5 - JavaScript Functions and Bootstrap
Practiced JavaScript functions and explored Bootstrap styles and components for building responsive webpages. This activity helped me understand how reusable functions and a CSS framework can improve functionality and layout.

### Week 6 - API & Client Storage
This activity focuses on working with APIs and client-side storage in web development. It helps demonstrate how web applications can retrieve data and store information in the browser. 

### Week 7 - Mini Full Stack Starter
This activity focuses on organizing a starter web application and applying concepts learned throughout the previous weeks. It provides practice in structuring project files and combining web development techniques into one project.
